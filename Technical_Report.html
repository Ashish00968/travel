prefers-reduced-motion Strategy

Unlike a blanket "disable all animations" approach, the v12 strategy removes movement (transform, translate) while preserving opacity and color transitions — keeping the UI feeling responsive for users who need it.

@media (prefers-reduced-motion: reduce) {
  .reveal, .reveal-left, .reveal-scale {
    transform: none !important;              /* Remove movement */
    transition: opacity 0.3s ease !important; /* Keep fade */
  }
  .shimmer-card::after { animation: none !important; }
}

12.3 — Dual-Ring Cursor System (Cursor.tsx)

Upgraded from a single 16px dot to a premium dual-ring system with spring-lerp physics. Zero React re-renders on mouse movement — all updates via direct DOM mutation in requestAnimationFrame.

ElementSizeFollow MethodHover Behavior
Inner dot8pxInstant (rAF direct write)Fades to opacity 0 on interactive elements
Outer ring36px → 52pxSpring lerp (factor 0.14)Expands to 52px, border brightens to 0.9 opacity
 
// Spring lerp loop — runs at 60fps without React setState
const animateRing = () => {
  ringX = lerp(ringX, targetX, 0.14);
  ringY = lerp(ringY, targetY, 0.14);
  ring.style.transform = `translate3d(${ringX-18}px, ${ringY-18}px, 0)`;
  rafId = requestAnimationFrame(animateRing);
};
⚡
Performance: The cursor runs entirely outside React's render cycle. mousemove updates target coordinates in a useRef, and the rAF loop reads them directly — achieving sub-frame latency without any virtual DOM diffing cost.

12.6 — ExpeditionGrid Parallax Cards (ExpeditionGrid.tsx)

Parallax Image on Place Cards

On mouse move, the inner image translates at 0.5× inverse of cursor position — creating a depth illusion where the image moves against the card.

const handleMouseMove = (e: React.MouseEvent<HTMLDivElement>) => {
  const rect = e.currentTarget.getBoundingClientRect();
  const x   = (e.clientX - rect.left)  / rect.width  - 0.5;
  const y   = (e.clientY - rect.top)   / rect.height - 0.5;
  // Image moves at 0.5x inverse — CSS transition smooths it
  imgRef.current.style.transform = `scale(1.08) translate(${-x*12}px, ${-y*8}px)`;
};
