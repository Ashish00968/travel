Cloudinary Media Infrastructure

The project uses a structured, dynamic media delivery system to ensure high-fidelity visuals across all devices.

1. Folder Hierarchy

Assets are organized to match the data model's hierarchy. This allows for automated URL generation and clean asset management.

2. Transformation Logic

URLs are constructed dynamically using specialized transformation strings for performance.

Parameter Technical Role Benefit
q_auto Automatic Quality Reduces file size by identifying the optimal compression level.
f_auto Automatic Format Serves Next-Gen formats (WebP/AVIF) to browsers that support them.
w_50 Width Resizing Generates a tiny 50px version for the blur placeholder.
e_blur:200 Blur Effect Applies a heavy Gaussian blur to the placeholder asset.

3. Dynamic Placeholder Injection

The system utilizes a Regex-based transformation swapper to generate Low-Quality Image Placeholders (LQIP) from existing URLs.

// Swaps 'q_auto,f_auto' with blur parameters
export function blurPlaceholderFromUrl(url: string): string {
  return url.replace(/\/upload\/[^/]+\//, `/upload/w_50,e_blur:200,q_10,f_auto/`);
}

Technical Data Specifications

Detailed breakdown of the core interfaces and types used in the himalaya.ts engine.

TrekStop (Discriminated Union)

Enforces data integrity by requiring specific fields based on the type property.

  • type: 'photo' | 'video' → mediaUrl is Mandatory.
  • type: 'text' → mediaUrl is Forbidden (never).
  • type: 'summit' → mediaUrl is Optional (hero fallback).

HimalayaPlace Structure

The primary object for every destination on the map.

interface HimalayaPlace {
  id: string;             // Unique identifier
  name: string;           // Display title
  lat: number;            // Latitude coordinate
  lng: number;            // Longitude coordinate
  type: PlaceType;        // Category (road, trek, etc.)
  image: string;          // Cloudinary URL via buildCloudinaryUrl()
  trekStops?: TrekStop[]; // Array of narrative moments
  videoTransitionUrl?: string; // Optional Earth Studio MP4
}

The Performance Engine

O(1) Global Index

At the module level, we derive a flat map of all places across all regions. This eliminates $O(N)$ search overhead during navigation transitions.

export const PLACE_INDEX: Record<string, HimalayaPlace> = 
  Object.fromEntries(HIMALAYA_REGIONS.flatMap(r => ...));

Scroll-Band Bucketing

To ensure smooth 60fps animations on complex pages, stops are bucketed into 10% scroll-depth windows. This allows the Intersection Observer to resolve active stops in constant time.
